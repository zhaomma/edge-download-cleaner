# 下载记录定时清理器（Edge 扩展）

一款 Microsoft Edge（兼容 Chrome）扩展：点击「启动」后按设定秒数循环倒计时，到点**自动清除浏览器下载记录**。循环在后台运行，弹窗关闭不影响清理。

> 只删除下载记录（edge://downloads 列表条目），**不会删除磁盘上的下载文件**。

---

## 功能特性

- **秒级倒计时循环**：任意秒数（≥1 秒）都精确支持，到点自动清理并进入下一轮，无需重复点击
- **后台独立运行**：清理由后台 Service Worker + 毫秒级闹钟驱动，弹窗开或关都照常执行
- **启动 / 停止 / 立即清理**：随时手动控制；「立即清理」不清空定时循环
- **状态一目了然**：剩余倒计时、运行中/已停止徽标、最近清理时间与条数
- **状态自动恢复**：设置保存在浏览器本地，重新打开弹窗自动恢复倒计时显示
- **隐私友好**：全部逻辑在本机运行，不上传任何数据

## 安装步骤

1. 打开 Edge，在地址栏输入 `edge://extensions` 并回车
2. 打开左下角「**开发人员模式**」开关
3. 点击「**加载解压缩的扩展**」，选择本项目文件夹 `edge-download-cleaner`
4. 安装成功后，工具栏出现本扩展图标

> 扩展更新后：回到 `edge://extensions` 点击该扩展卡片上的「**重新加载**」即可生效。

## 快速上手（30 秒自测）

1. 先随便下载一个文件（确认 `edge://downloads` 里有记录）
2. 点工具栏图标打开弹窗，秒数填 `10`
3. 点「**启动**」→ 倒计时开始
4. 归零后打开 `edge://downloads`：记录已清空，弹窗倒计时自动进入下一轮

## 使用说明

| 界面元素 | 说明 |
|---|---|
| 倒计时大字 | 距下次清理的剩余时间（时:分:秒） |
| 运行中 / 已停止 | 当前循环状态徽标 |
| 每轮秒数 | 一轮循环的时长，运行中不可修改（停止后可改） |
| 启动 / 停止 | 开始或终止循环 |
| 立即清理 | 立刻清空当前下载记录，不影响循环计时 |
| 最近清理 | 上次清理的时间与条数 |

## 行为边界（重要）

| 场景 | 行为 |
|---|---|
| 弹窗关闭 | 循环不受影响，后台到点照常清理 |
| 点击「停止」 | 清除闹钟，循环终止；之后不再自动清理 |
| Edge 完全退出 | 循环暂停；重新打开 Edge 后，若已到清理点会自动清一次并继续下一轮（这是浏览器对闹钟的调度行为，非主动补偿） |
| 修改秒数 | 仅在停止状态下可改，改后点「启动」按新秒数开始 |
| 磁盘文件 | 始终不动，只清记录 |

## 常见问题

**Q：弹窗关掉后还会清理吗？**
会。循环引擎在后台 Service Worker 中，弹窗只是显示与控制界面。

**Q：会删除我下载的文件吗？**
不会。扩展只清除下载记录条目，文件原样保留在磁盘。

**Q：Edge 重启后为什么立刻清了一次？**
重启前如果刚好错过了清理点，浏览器会把这次闹钟补触发一次，之后恢复正常循环。

**Q：加载时报错 / 不生效？**
确认：① `edge://extensions` 已开启开发人员模式；② 选中的是包含 `manifest.json` 的 `edge-download-cleaner` 文件夹本身；③ 加载后点过扩展图标。仍异常请把错误提示发我。

**Q：和 Chrome 通用吗？**
通用。Edge 与 Chrome 同属 Chromium 内核，本扩展在 Chrome 的 `chrome://extensions` 用同样方式加载即可。

## 技术实现简表

| 模块 | 实现 |
|---|---|
| 权限 | `downloads`（清记录）、`storage`（存状态）、`alarms`（定时触发） |
| 调度 | `chrome.alarms` 一次性闹钟，`when` 精确到毫秒；触发后按秒数续排下一轮 |
| 状态共享 | `chrome.storage.local` 保存 running / 秒数 / endTime / 清理记录 |
| 清理 | `chrome.downloads.search()` 计数 → `chrome.downloads.erase()` 清空 |
| 弹窗显示 | 250ms 刷新，每秒与后台同步一次状态 |
| 架构 | Manifest V3：Service Worker 无独立页面，事件驱动、按需唤醒 |
